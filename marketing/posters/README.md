# Trial posters (source)

Source of the Design canvas https://claude.ai/artifact/G3orczVQJTPaMtdz9crLZr (US Letter, 816×1056 px each).
`canvas.json` is the canvas index; each `*.dc.html` is one poster. All posters and the two one-page flyers (`Flyer-EN`, `Flyer-VI`) are published. To republish: publish these files under `project/` to that canvas.
